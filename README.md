# AI 협업 가이드

기획·디자인·개발·QA·PM이 AI와 함께 일하는 방법을 소개하는 입문 교육 자료입니다. 필요한 자료와 기준을 연결하고, 결과를 검토·수정한 뒤 다음 작업에 사용할 기록을 남기는 과정을 설명합니다.

**[발표 자료 바로 보기](https://minsukong.github.io/ai-collaboration-guide/)**

## 발표 화면 사용법

- 화면 아래 화살표나 오른쪽 장면 번호를 눌러 이동합니다.
- `←`·`→` 또는 `Page Up`·`Page Down`으로 이전·다음 장면으로 이동합니다. 도입부에서는 `↑`·`↓`도 사용할 수 있습니다.
- `Home`·`End`로 처음·마지막 장면으로 이동합니다.
- `F` 또는 ‘전체 화면’ 버튼으로 전체 화면을 전환합니다.
- 본문은 아래로 스크롤해 읽을 수 있습니다. 도입부 마지막 장면에서 본문으로 이어집니다.

## 파일과 편집 기준

- `index.html`: 발표 자료 시작 화면
- `01_intro.html`: 도입부 발표 화면
- `02_briefing.html`: 본문 발표 화면
- `assets/`: 공통 스타일과 화면 이동 기능
- `01_도입부.md`: 도입부 원고
- `02_AI_협업_교육_발표초안.md`: 본문 원고와 검토용 발표 설명
- `03_화면구성안.md`: 화면 구성 기준
- `skills/korean-work-writing/`: 공유용 글쓰기 스킬과 예시

Markdown을 내용 기준으로 관리합니다. 원고를 수정하면 해당 HTML도 함께 수정해야 합니다. 발표 설명과 검토 메모는 발표 화면에 넣지 않습니다.

별도 설치나 빌드 없이 GitHub Pages에서 열 수 있습니다. 로컬에서는 이 폴더를 내려받아 `index.html`을 브라우저로 열면 됩니다.
