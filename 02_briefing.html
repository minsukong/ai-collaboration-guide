01 / 12 · AI 협업 업무 방식

AI 활용을 실제 업무로 연결하기

AI가 만든 결과를 다음 업무에서도 활용할 수 있어야 합니다.

각 파트의 자료를 AI가 참고하도록 연결하고, 작업 결과를 확인해 다음 담당자에게 전달하는 방법을 살펴봅니다.

  • 이번 작업에 필요한 자료와 기준을 확인합니다.
  • AI와 작업하고 결과가 기준에 맞는지 검토합니다.
  • 결정한 내용과 남은 일을 기록해 다음 작업으로 연결합니다.

02 / 12 · AI 협업 업무 방식

작업이 이어질 때 놓치기 쉬운 정보

같은 기능을 작업해도 서로 다른 기준을 참고하면 결과가 달라집니다.

예를 들어 이용권 취소 기능을 만든다고 가정합니다. (실제 서비스 정책이 아닌 설명용 예시)

파트먼저 확인할 내용빠졌을 때 생기는 문제
기획취소 조건과 예외, 결정된 정책화면별 설명이 달라짐
디자인상태별 안내와 사용자 흐름필요한 오류·완료 상태 누락
개발정책과 API 계약, 처리 결과일부 조건만 구현
QA수용 기준과 변경 사항확인해야 할 경우를 놓침
PM결정 사항과 영향받는 작업일정·담당 조정이 어려워짐

중요한 것은 AI가 어떤 답을 했는지보다 어떤 자료를 기준으로 작업했는지입니다.

03 / 12 · AI 협업 업무 방식

공통 기준은 어디까지 필요한가

파트별 업무 방식은 유지하고, 함께 확인할 기준을 연결합니다.

  • 작업 근거: 어떤 문서와 결정을 참고했는가
  • 작업 범위: 이번에 무엇을 하고 무엇은 제외하는가
  • 완료 기준: 어떤 결과가 나와야 완료인가
  • 확인 결과: 무엇을 검증했고 무엇은 확인하지 못했는가
  • 다음 작업: 누가 무엇을 결정하거나 이어서 처리해야 하는가

기획서, 디자인 파일, 소스 코드는 서로 다릅니다. 모든 파트가 같은 양식을 사용할 필요는 없지만, 연결되는 정보는 찾을 수 있어야 합니다.

06 / 12 · AI 협업 업무 방식

우리가 사용하는 AI 협업 흐름

사람이 방향과 기준을 정하고, AI와 작업한 결과를 함께 확인합니다.

1. 준비

목적·범위·자료·완료 조건을 정합니다.

2. 작업

AI가 필요한 문서와 기존 결과를 확인하고 초안이나 구현을 만듭니다.

3. 검증

정책·화면·테스트 등 업무에 맞는 기준으로 결과를 확인합니다.

4. 수정

문제와 원인을 전달하고 수정한 뒤 다시 확인합니다.

5. 기록

결정·변경·검증 결과와 남은 일을 다음 작업으로 연결합니다.

검증 → 수정 → 다시 확인 ↺

검증에서 문제가 나오면 수정 단계로 돌아가고, 기록한 내용은 다음 작업의 시작 자료가 됩니다.

08 / 12 · AI 협업 업무 방식

실제로 준비한 두 가지 사례

프론트 docs와 백엔드 dev_guide는 작업 기준을 AI와 연결하기 위해 준비한 사례입니다.

프론트 docs

  • 작업 종류에 따라 필요한 가이드와 스킬을 선택합니다.
  • 작업 카드에 범위·완료 조건·검증 결과를 남깁니다.
  • 결정과 미완료 항목을 다음 작업으로 연결합니다.

백엔드 dev_guide

  • 개발자와 AI가 협업하는 순서를 안내합니다.
  • 설계·구현·테스트·리뷰의 확인 기준을 연결합니다.
  • 필요한 프로젝트 지식을 docs로 확장합니다.

백엔드 docs 확장 안내 · 발췌

09 / 12 · AI 협업 업무 방식

읽고 이해하기 쉬운 문서 만들기

AI가 작성한 문서는 내용뿐 아니라 읽고 이해하기 쉬운지도 확인해야 합니다.

예시 — 추상적인 표현을 구체적으로 다듬기

표현독자가 읽을 때
“AI 활용의 효과를 일회성 산출물에서 지속 가능한 업무 수행으로 확장합니다.”의미를 풀어 읽어야 하고 실제로 무엇을 하자는지 바로 드러나지 않습니다.
“AI가 만든 결과를 다음 업무에서도 활용할 수 있어야 합니다.”필요한 행동과 목적을 바로 이해할 수 있습니다.

문서 품질을 떨어뜨리기 쉬운 표현

  • 추상적인 명사와 번역투가 많아 실제 행동이 보이지 않는 문장
  • 중요한 설명 없이 전문 용어만 이어 붙인 문장
  • 비슷한 의미를 반복하거나 핵심보다 형식을 앞세운 문장
  • 독자에게 익숙한 업무 표현을 불필요하게 어렵게 바꾼 문장

좋은 문장은 단순히 짧은 문장이 아닙니다. 필요한 정보와 판단 기준이 정확하고 자연스럽게 전달되는 문장입니다.

스킬은 필요한 것만 골라 적용하기

스킬을 적용해도 결과가 맞는지는 확인해야 합니다.

  • 이번 작업에 맞는 스킬을 선택하고 실제 적용한 기준을 확인합니다.
  • 겹치거나 충돌하는 지침은 적용 범위와 우선순위를 정리합니다.
  • 결과가 나빠지면 지침을 계속 추가하기보다 기존 내용을 고칩니다.
  • 사람이 결과를 검토하고, 실제 사용 결과로 스킬을 보완합니다.

12 / 12 · AI 협업 업무 방식

각자의 업무에서 시작하기

반복해서 수행하는 업무 하나를 선택해 AI와 함께 진행해 봅니다.

  1. 이번 작업의 목적과 결과를 정합니다.
  2. 참고할 자료와 완료 기준을 연결합니다.
  3. AI와 작업한 뒤 실제 결과를 확인합니다.
  4. 수정 사항과 결정·검증 결과를 남깁니다.
  5. 반복해서 쓸 작업 방법은 스킬로 정리하고, 다음 작업에서 기록과 함께 활용합니다.

AI로 초안과 구현 시간을 줄일 수 있어도 여러 회사가 합의하고 검증해 납품을 완료하는 과정은 남습니다.
